## Lab persona (use consistently)

- **Name:** Northline Comfort (Lab)  
- **Trade:** Residential HVAC  
- **Market:** Fictional suburb cluster, ~180k population  
- **Hours:** Mon–Fri 8–5; on-call tech but slow SMS  
- **Pain:** ~30% of web leads after 5pm; weekend voicemail pile  
- **Stack:** Google Calendar + Jobber sandbox (or Calendar-only if no Jobber)  
- **Rules:** 25-mile radius; no commercial chillers; emergency fee disclosed; escalate if customer upset

---

## Test protocol (honest method)

1. **Build** Starter Desk config for Northline Comfort (Lab).  
2. **Generate 40 scripted leads** over 14 days: 20 calls (or call simulations) + 20 form fills. Mix quality.  
3. **Log every event:** timestamp in → first response → qualified Y/N → booked Y/N → escalate Y/N.  
4. **Human review** 100% of transcripts for tone failures.  
5. **Publish only measured lab numbers** + methodology. No “client saved $X” claims.

### Suggested metrics to report (fill after run)
- Median first response time (target &lt;60s on forms/SMS)  
- Qualification rate  
- Booked appointments  
- False-book rate (out-of-area that slipped)  
- Escalations handled correctly  

*Until the run is complete, sales uses the outline + Loom of the empty flow — not fabricated stats.*

## Day 5 — 48-hour plumbing install list (thread)

**Post 1/6**
```
If I had 48 hours to install speed-to-lead for a plumbing shop, this is the list.

No rebrand. No new website. Just stop losing after-hours jobs.
```

**Post 2/6**
```
Hour 0–2: Map reality

• Where leads enter (Google call, website form, Angi)
• Who answers 8–5 vs after hours
• What “qualified” means (ZIP list, residential only, emergency fee)
• Where bookings should land (Jobber / HCP / Google Calendar)
```

**Post 3/6**
```
Hour 2–8: Wire intake

• Missed-call / overflow → AI voice or immediate SMS callback path
• Form webhook → SMS in under 60 seconds
• Disqualify out-of-area automatically
• Escalate angry callers to the owner
```

**Post 4/6**
```
Hour 8–16: Booking

• Expose real slots (not “we’ll call you”)
• Confirm by SMS
• Create calendar event + owner ping
• Log disposition: booked / callback / rejected
```

**Post 5/6**
```
Hour 16–48: Harden

• 10 scripted test calls (emergency, tire-kicker, out-of-area)
• Fix tone and fee disclosure
• One-page owner playbook: when to jump in
• Go live on nights/weekends first
```

**Post 6/6**
